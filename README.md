### 👨‍💻 About Me

I am a **Full-Stack Web Developer** specializing in **Laravel**, **Vue.js**, and **MySQL**. I focus on building scalable enterprise applications, streamlining business operations, and crafting responsive, intuitive user interfaces.

- 🔭 **Currently working on:** Developing an end-to-end **Human Resources Information System (HRIS)** web application with modular architecture, automated reporting, and administrative dashboards.
- 🌱 **Exploring & Scaling:** Containerization and deployment workflows using **Docker**, along with system optimization and clean backend architecture.
- 💡 **Core Focus:** Translating complex operational requirements into reliable, maintainable, and high-performance web solutions.
- 💬 **Ask me about:** `PHP`, `Laravel`, `Vue.js`, `MySQL`, `RESTful APIs`, and `Docker`.
